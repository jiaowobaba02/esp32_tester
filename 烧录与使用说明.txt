========================================
 ESP32 刷题机 正式版 v2.0
========================================

【固件文件】firmware/
  bootloader.bin / partition-table.bin / st6201_spi_lcd.bin

【烧录方法】(需要 ESP-IDF 环境, 或 pip install esptool)

  python -m esptool --chip esp32 -p /dev/ttyUSB0 -b 460800
    --before default_reset --after hard_reset write_flash
    --flash_mode dio --flash_freq 40m --flash_size 4MB
    0x1000 firmware/bootloader.bin
    0x8000 firmware/partition-table.bin
    0x10000 firmware/st6201_spi_lcd.bin

  完全擦除(清空所有数据, 慎用):
  python -m esptool --chip esp32 -p /dev/ttyUSB0 erase_flash

【首次使用】
  1. 上电 -> 设置 -> 扫描 WiFi -> 输入密码
  2. WiFi 连接后, 浏览器打开 http://设备IP:8080 粘贴 DeepSeek API Key
  3. 开始刷题
